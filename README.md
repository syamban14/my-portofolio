# M. Syamsul — Interactive AI Studio & Living Workspace Portfolio

Portofolio web interaktif **M. Syamsul (IT Programmer & AI Specialist)** berbasis **Vite + Vanilla ES Modules + HTML5 Canvas + CSS Custom Properties**, tayang melalui **GitHub Pages**.

- **Website Live:** https://syamban14.github.io/my-portofolio/
- **CV ATS-Friendly (Bahasa Indonesia):** https://syamban14.github.io/my-portofolio/cv/M-Syamsul-CV-ATS-ID.pdf
- **CV ATS-Friendly (English):** https://syamban14.github.io/my-portofolio/cv/M-Syamsul-CV-ATS-EN.pdf

## Fitur Utama

1. **Living Workspace Diorama 2.5D & Mode Waktu (`Pagi | Senja | Malam`)**
   - Rig kanvas karakter 2x DPR dengan kedipan mata natural, ekspresi senyum interaktif, gerak mulut *lip-sync*, dan pencahayaan *rim-light* dinamis mengikuti sakelar lampu meja dan waktu.
   - Langit jendela dua panel (bintang, bulan sabit, bintang jatuh, awan senja/pagi, sorot matahari), bayangan lantai dinamis, serta layar laptop aktif.
2. **Tanya AI Syamsul & Context Inspector**
   - Pertanyaan cepat dwibahasa (`ID | EN`), perintah studio langsung (`/pagi`, `/senja`, `/malam`, `/lampu`, `/en`, `/id`, `/cetak`), dan inspektor data terstruktur yang sinkron.
3. **Konstelasi Keahlian Berbasis Fisika Kanvas**
   - Graf node 10 kompetensi lintas AI, Language, Database, dan Tech yang dapat diseret, difilter, dan ditautkan langsung ke proyek terkait.
4. **Simulasi 5 Proyek, Pratinjau UI, & Integrasi Live GitHub (`@syamban14`)**
   - Simulasi interaktif dan mockup antarmuka untuk **Aplikasi Presensi Online (BCS Logistics)**, **Aplikasi Kesehatan doklinc**, **Aplikasi Ujian Online**, **Aplikasi Test Online Masuk**, dan **Aplikasi Surat (LP3I College)**.
   - Sinkronisasi repositori publik langsung dari GitHub REST API lengkap dengan filter kategori, pencarian, dan tautan demo 3D (`step-100-3d`, `beach-3d`).
5. **Scrubber Jejak Karir (`2011 - 2026`), Composer Kolaborasi, & Ekspor CV ATS**
   - Filter karir/pendidikan/prestasi + slider tahun, composer brief WhatsApp/Email otomatis, palet perintah `Cmd+K`, serta generator CV ATS-friendly PDF.

## Pengembangan Lokal

```bash
npm install
npm run generate:cv   # (opsional) regenerate CV ATS PDF di public/cv/
npm run dev           # jalankan server dev lokal
npm run build         # kompilasi produksi ke dist/
```
